Privacy Policy

Last updated: August 2026

Overview

Hebra is designed with privacy as a core principle. We collect no personal data, store no user information, and include no tracking or analytics.

Data We Collect

None. Hebra does not collect, store, or transmit any personal information. Specifically:

  • No accounts, emails, or phone numbers are required.
  • No analytics, crash reporting, or usage tracking.
  • No cookies, fingerprinting, or advertising identifiers.
  • No data is sold to or shared with third parties.

How Calling Works

Hebra uses WebRTC for peer-to-peer video calls. Audio and video streams travel directly between paired devices with end-to-end encryption — they never pass through our servers.

Our signaling server (a Cloudflare Worker) only relays the initial connection handshake. It does not store call history, metadata, or any personal data. The signaling server is stateless between calls.

Push Notifications

Hebra uses Apple's PushKit (VoIP) to deliver incoming call notifications. A device token is exchanged during the signaling handshake to enable push delivery. This token is ephemeral and is not stored on any server after the signaling session ends.

Linking Codes

The 6-digit linking code used to pair devices is stored only on-device in the app's local storage. It is transmitted to the signaling server solely to match paired devices during a call session. It is not logged or persisted server-side.

Third-Party Services

Hebra uses the following infrastructure services, none of which receive personal data:

  • Cloudflare Workers & Durable Objects — stateless signaling relay.
  • Cloudflare Calls (TURN) — relay for NAT traversal when direct peer-to-peer connection isn't possible.
  • Apple Push Notification service (APNs) — VoIP push delivery.

Children's Privacy

Hebra does not collect any data from any user, including children. The app is rated 4+ and is safe for all ages.

Changes to This Policy
