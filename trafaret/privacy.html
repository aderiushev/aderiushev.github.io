Privacy Policy

Effective October 9, 2026

This policy covers the public Trafaret demo at trafaret.onrender.com. If you run Trafaret yourself from the source code, nothing reaches me at all.

In short: no accounts, no cookies, no analytics — and what you run is kept in memory only.

What the demo handles

  • The prompts and instructions you type, the photos you upload, and the images the models produce.
  • The workflow itself — which blocks you placed and how they are wired. It is saved in your own browser (local storage), not on the server. Clearing the site's data in your browser removes it.

Where it goes

  • When you press Run, the server sends the prompt and any input images to the provider of the model you picked: Cloudflare Workers AI for FLUX.2 klein, or BytePlus ModelArk for Seedream 4.5. Their own terms and privacy policies apply to that processing. The Mock model never leaves the server.
  • The server runs on Render, in Frankfurt, behind Cloudflare. As with any website, these hosting providers process your IP address to deliver requests and may keep their own technical logs.

How long it stays

  • The server has no database and writes nothing to disk. Uploads and results live in memory, a finished run is forgotten an hour later, and older images are dropped when memory fills up.
  • Everything is gone whenever the server restarts or falls asleep, which on the free instance happens after 15 idle minutes.
  • To share the demo fairly, the server counts requests per visitor IP address for ten minutes, in memory, and keeps nothing afterwards.

What it does not do

  • No accounts, sign-in or email. No cookies, analytics, ads or trackers.
  • Images are not shared with other visitors, but the demo is not meant for private material: please do not upload personal or sensitive photos.

If this policy changes, the new version will appear at this address with a new effective date.
