Support

Answers about the live demo

The demo takes a minute to open

It runs on a free instance that sleeps after 15 idle minutes. The first visit wakes it up — keep the tab open and it loads in about a minute.

A result is labelled Mock

The real models have small daily caps on the demo. Once a cap is reached, jobs run on the Mock model instead and say so. The caps reset at 00:00 UTC.

Seedream 4.5 shows an error

The demo uses Seedream's free quota only, and the service pauses when it runs out. Pick FLUX.2 klein or Mock in the block's Model menu and run again.

"Too many requests"

To keep the demo fair, each visitor can start 20 runs or retries and 30 uploads per ten minutes. Wait a few minutes and try again.

My workflow disappeared

Workflows are saved in your browser, so another browser, a private window or cleared site data starts fresh. Use Export to keep a copy as a file, and Import to bring it back.

Can I run it myself?

Yes — the source is on GitHub, and pnpm install then pnpm dev starts it locally with the Mock models, no keys needed.
